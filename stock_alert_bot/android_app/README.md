# StockPro Android App

This is a clean Android wrapper app for the StockPro dashboard.

## Purpose
The app loads the web dashboard in a WebView so it behaves like a mobile application while staying connected to your backend.

## Build
Open this folder in Android Studio and run the app on a device or emulator.

## URL loaded
- https://kunal-analysis.web.app

## Notes
- This project is intentionally simple and stable for app-shell usage.
- For production, use secure release signing and a proper app architecture.
